                              OVERVIEW
================================================================================

A speed upgrade system has been added to the game that allows players to 
increase their movement speed by 1.5x (from 5.0 to 7.5 units/second) by 
collecting 10 items and purchasing the "Speed Boost" card from the shop.

The upgrade is permanent, persists across game sessions, and cannot be 
purchased more than once.

================================================================================
                        SYSTEM MECHANICS
================================================================================

UNLOCK CONDITION:
• Player must collect 10+ food items across any levels

APPEARANCE:
• When condition met, "Speed Boost" card appears in shop
• Only appears once; disappears after purchase

COST:
• 10 items (same as other shop items)
• Deducted from total_food_owned when purchased

EFFECT:
• Base speed: 5.0 units/second
• After upgrade: 5.0 × 1.5 = 7.5 units/second
• Player movement is 50% faster

DURATION:
• Permanent upgrade
• No time limit or duration
• Applies to all levels until reset

PERSISTENCE:
• Saved to: user://speed_upgrades.save
• Purchased item tracked in: user://purchased_items.save
• Loads automatically on GameManager startup
• Persists across multiple game sessions

LIMITATIONS:
• Can only be purchased once
• Cannot be resold or "downgraded"
• Resets when "Restart" button is pressed in shop

================================================================================
                      IMPLEMENTATION DETAILS
================================================================================

GAMEMANAGER SPEED SYSTEM:
```
speed_multiplier: float = 1.0    // Default: no upgrade
apply_speed_upgrade()             // Sets to 1.5 and emits signal
save_speed_upgrades()             // Persists to disk
load_speed_upgrades()             // Loads from disk on startup
```

PLAYER SPEED CALCULATION:
```
const BASE_SPEED = 5.0
var current_speed = BASE_SPEED * GameManager.speed_multiplier

// With speed upgrade:
current_speed = 5.0 × 1.5 = 7.5
```

SHOP CARD GENERATION:
```
if GameManager.total_food_owned >= 10 and 
   not GameManager.is_item_purchased("speed_upgrade"):
    // Create "Speed Boost" card
```

PURCHASE HANDLING:
```
SellThing._input() detects click
  → GameManager.total_food_owned -= 10
  → GameManager.add_purchased_item("speed_upgrade")
    → GameManager.apply_speed_upgrade()
      → speed_multiplier = 1.5
      → emit_signal("speed_upgraded", 1.5)
      → GameManager.save_speed_upgrades()
    → mark_as_purchased()
      → save_purchased_items()
  → card.queue_free()
```

SIGNAL FLOW:
```
GameManager.speed_upgraded signal emitted
  ↓
Player._on_speed_upgraded() callback
  ↓
update_speed_from_multiplier()
  ↓
current_speed = BASE_SPEED × speed_multiplier
  ↓
_physics_process() uses updated current_speed
  ↓
Player movement applies new speed
```

================================================================================
                        TROUBLESHOOTING
================================================================================

IF SPEED BOOST DOESN'T APPEAR IN SHOP:
1. Check GameManager.total_food_owned >= 10
2. Verify GameManager.is_item_purchased("speed_upgrade") == false
3. Check console for errors
4. Ensure Shop.gd modifications are loaded

IF SPEED DOESN'T INCREASE AFTER PURCHASE:
1. Check console for "Speed upgraded!" message
2. Verify GameManager.speed_multiplier == 1.5
3. Check Player.current_speed == 7.5
4. Ensure Player.gd _ready() called update_speed_from_multiplier()

IF SPEED RESETS UNEXPECTEDLY:
1. Check speed_upgrades.save file exists
2. Verify load_speed_upgrades() is called in GameManager._ready()
3. Check for errors in save/load functions

IF CRASH OR ERROR OCCURS:
1. Check console output for error messages
2. Verify all 4 files are properly saved
3. Try reloading the scene
4. Clear editor cache if needed
