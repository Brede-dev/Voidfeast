================================================================================
PERSISTENCE - WHAT GETS SAVED:
================================================================================

File: user://total_food.save
  Contains: total_food_owned integer
  When: After every item collection

File: user://speed_upgrades.save
  Contains: speed_multiplier float
  When: After purchasing speed upgrade

File: user://purchased_items.save
  Contains: Array of item IDs
  When: After any purchase

Deleted by Restart Button:
  - user://total_food.save
  - user://speed_upgrades.save
  - user://purchased_items.save

================================================================================
CUSTOMIZATION:
================================================================================

To change speed multiplier (default: 2.0x faster):

  File: GameManager.gd
  Line: 26
  
  Current:
    func apply_speed_upgrade() -> void:
      speed_multiplier = 2.0
  
  Change 2.0 to:
    1.5 = 50% faster
    2.0 = DOUBLE speed (current)
    2.5 = 2.5x speed
    3.0 = TRIPLE speed

To change upgrade cost (default: 10 items):

  File: HUD.gd
  Line: 94
  
  const SPEED_UPGRADE_COST: int = 10
  
  Change 10 to: 5, 15, 20, etc.

To change when upgrade is available (default: 10 items):
  
  Same as above - both are the same value

================================================================================
DEBUGGING:
================================================================================

To see what's happening:

  In GDScript console (Ctrl+D):
  
  print(GameManager.total_food_owned)        # Current items
  print(GameManager.speed_multiplier)        # 1.0 or 2.0
  print(GameManager.can_afford_speed_upgrade())  # true/false
  
  Check files exist:
    user://total_food.save
    user://speed_upgrades.save
    user://purchased_items.save

If items don't persist:
  - Verify Food/Item class calls GameManager.collect_food()
  - Check that save files are being created
  - Check user:// directory permissions

If speed doesn't apply:
  - Verify player.gd has: current_speed = BASE_SPEED * GameManager.speed_multiplier
  - Check speed_multiplier is being saved (2.0)
  - Verify player uses current_speed not BASE_SPEED
